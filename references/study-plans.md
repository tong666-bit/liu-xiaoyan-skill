# 备考计划：诊断、时间预算与调整

所有时长为可调整的教学建议。考试日期先核验；2026下半年四六级快照见 [exam-facts.md](exam-facts.md)，以后不要自动沿用。

## 最少输入

考试/科目、日期、当前分项表现、每天可用时间。优先用最近限时材料和成绩分项，不只猜词汇量。用户已提供的信息不重复问；缺项时合并询问并提供标注假设的起步版。

## 每天2小时的四六级示例

| 任务 | 时间 | 交付物 |
|---|---|---|
| 词汇到期复习+新词 | 20分钟 | 能闭卷说出的语境卡 |
| 听力 | 30分钟 | 一段+一个错因+重听复述 |
| 阅读 | 35分钟 | 限时一篇+错题证据 |
| 写作/翻译轮换 | 20分钟 | 一个段落或一组信息块 |
| 回顾 | 15分钟 | 一条下次动作、安排复测 |
| 合计 | 120分钟 | 按实际完成记录 |

听力从开始就训练，不拖到最后两周。基础差可以减少新词和题量，保留每项反馈闭环。

## 12周框架

- 第1–3周：补阻碍理解的语法/词汇；同步做短听力与短阅读，建立错因记录。
- 第4–8周：按薄弱题型专项练；阅读讲证据，听力做正常速度复测，每周至少一次写译反馈。
- 第9–10周：组合限时任务，验证阅读顺序和时间预算。
- 第11–12周：完整模考与复盘、到期错题复测，避免临时堆大量未消化课程。

每周留一天做调整/补欠，不要求天天达到固定课数。课程是理解工具，只有“能独立完成一题”才是完成标准。

## 4周压缩框架

第1周先诊断并抓两类主要错因；第2–3周交替专项和组合限时；第4周完整模考+重做典型错题+写译检查。
不承诺500高频词够用，不一刀切取消选词填空训练。有限时间可降低其投入，但需保留基础词性和考场完成策略。

## 每天3小时的考研示例

| 任务 | 时间 |
|---|---|
| 词汇闭卷复习 | 30分钟 |
| 阅读限时+关键句精读+证据复盘 | 70分钟 |
| 翻译/新题型/完形轮换 | 30分钟 |
| 应用文或大作文片段+修改 | 30分钟 |
| 错题复测与次日安排 | 20分钟 |
| 合计 | 180分钟 |

考研不安排四六级听力作为卷面专项；听力可为语言兴趣另练。英语一/二按翻译和作文差异调整。准备时间短也要先做应用文和翻译诊断，不能等阅读“学完”才开始。

## 按剩余时间而非固定月份规划

6个月：基础修补与题型初识 → 真题专项 → 组合限时 → 模考反馈。
3个月：诊断主错因 → 高频题型闭环 → 写译每周反馈 → 模考。
全年：按学习基础和学校任务分阶段；不强制从1月开始，不说“只许真题不许自编题”。自编题可修特定能力，但不能替代真题的考试适应。

## 每周调整规则

- 完成率偏低：先缩量，确保每项能核对/反馈；不要只延长学习时间。
- 新词次日忘得多：减少新词，补检索，参见 [vocabulary.md](vocabulary.md)。
- 熟题高分、陌生题低分：保留未做材料检查迁移，避免把记答案当学会。
- 听稿懂但耳朵不懂：补辨音；词都懂但句子不懂：补结构。
- 某模块连续卡住：缩小到一个错因、一项动作、一周后复测。

最终计划应给明确起止日期、每天任务、每周验收和调整条件，不只给“多背词、多做题”的口号。
