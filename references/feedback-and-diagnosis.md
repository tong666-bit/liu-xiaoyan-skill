# 批改、诊断与错题记录

评分是教学反馈，不能保证真实阅卷分数。缺题目要求时能先改语言，但扣题度判断需等题面齐全。

## 批改作文的顺序

1. 对照题面，检查任务和文体是否完成。
2. 说明观点、论证、组织是否清晰。
3. 找影响意思的语言错误，再处理搭配与自然度。
4. 保留正确表达，给最小修改版；需要时另给提升版。
5. 选最值得修的1–3处，让学生重写而不是只读范文。

| 层面 | 观察点 | 反馈表达 |
|---|---|---|
| 任务完成 | 对象、要求、文体、字数 | “漏了建议如何实施，需补一条具体动作。” |
| 组织 | 段落中心、前后衔接 | “此例没有解释你的理由，补因果关系。” |
| 语言 | 句法、搭配、语义 | 原句→最小修改→原因 |
| 表达 | 清晰、语域、冗余 | 准确之后再改自然 |

若按15分/20分制估计，注明采用的教学尺度、区间和不确定项；没读当次评分标准时不称官方评分。字数不足不编造固定扣分公式。

## 自编改错示例

原句：Everyone have different opinions, so we should respect others idea.
最小修改：Everyone has different opinions, so we should respect others' ideas.
解释：Everyone 对应单数谓语；others' 为所有格；ideas 用复数与不同观点对应。
任务：用 Everyone ... 写一句新的观点句，检查主谓一致。

## 阅读/听力诊断

记录答案与理由；猜对也可标风险。用“新题中是否仍犯同错”判断是否改进，二刷熟题高正确率不直接等于水平提高。

| 错因 | 证据 | 下周任务 |
|---|---|---|
| 词汇 | 关键义项误读 | 语境卡+搭配检索 |
| 结构 | 把从句谓语当主句谓语 | 每天2句分层 |
| 定位 | 回到共享关键词的错误段 | 写候选段差异 |
| 逻辑 | some→all、相关→因果 | 命题槽位对照 |
| 声音 | 看稿懂却听不出 | 短片段辨音 |
| 时间 | 后半空白、来回改答案 | 分段限时+止损 |

## 10–20 分钟初始诊断（建议）

用用户已有材料选一篇短阅读/一段听力，再让其写或译一小段。分别记录正确率、时间、犹豫和错因。没有音频可先完成文字任务，听力状态标待测。

不依据一次表现预测“肯定能过”。成绩分析要考虑题难、是否见过题、是否限时和材料是否完整。
