# 阅读：定位、命题比较与错因复盘

适用四六级阅读和考研传统阅读。题型与比例见 [exam-facts.md](exam-facts.md)。本文件是教学整理，不是命题机构保证的“规律”。

## 考场与课后分开练

**考场**：看题干任务，略读建立话题与段落功能，再按题定位精读。学生顺读更稳定时可以先读文章。初始参考为每篇 8–10 分钟，按正确率和个人速度调整。

**课后**：重做做错或猜对的题，复述段意，拆阻碍理解的句子，积累必要词汇。不是每次限时都逐字翻译，也不是永久只靠跳读。

## 题型与证据范围

| 题型 | 要找的证据 | 误区 |
|---|---|---|
| 细节 | 对应命题与限制条件 | 只匹配名词，忽略否定/对象 |
| 主旨/标题 | 全文中心问题与判断 | 把首段例子当中心 |
| 推断 | 文内前提能推出的最小结论 | 用常识添加事实 |
| 态度 | 谁评价什么、程度如何 | 把被引用专家当作者 |
| 词义 | 本句结构及邻句解释/对比 | 搬词汇书第一义 |
| 例证目的 | 例子支持的论点 | 只复述例子 |

细节题常可借行文顺序定位，它不是适用于所有题型的定理。不凭未统计数字声称“细节题占80%”。

## 选项比较：对象 / 动作 / 条件 / 范围 / 关系

| 错因 | 比较问题 |
|---|---|
| 无依据 | 原文真的提供这个信息吗？ |
| 对象偷换 | students 换成 all adults 了吗？ |
| 范围放大 | some 变 all，may 变 must 了吗？ |
| 因果倒置 | A→B 写成 B→A 了吗？ |
| 相关当因果 | 原文只是两者一起变化吗？ |
| 状态偷换 | 计划、建议、可能变成已实现了吗？ |
| 局部当整体 | 一种情形能覆盖全文吗？ |
| 答非所问 | 问原因却答结果/措施吗？ |

all/only/never 不自动错，原文支持绝对命题时可以正确；indifferent 不能凭“几乎不选”排除。同义词相似不等于整句命题相同。

## 完整演示（自编）

材料：A survey found that students who used the library regularly reported less stress. The researchers warned that the survey alone could not show whether library use reduced stress.

问题：What can be concluded from the survey?

A. Library use certainly causes stress to fall.
B. Regular library users reported lower stress, but causation was not established.
C. Every student can reduce stress by visiting the library.
D. The researchers advised closing other study spaces.

**答案 B**。第一句提供关联，第二句限定因果结论。reported lower stress 对应 reported less stress；causation was not established 对应 could not show whether ... reduced stress。A 把相关变因果，C 放大人群并保证效果，D 无依据。

迁移：去掉第二句也不能仅凭调查关联推出因果。不要靠“有转折就选转折后”代替判断。

## 长篇句段匹配

1. 每个陈述标一个稀有定位词和一个关系线索，如年份 + 政策变化。
2. 浏览段落，必要时记短功能标签：旧问题/新办法/反例/结论。
3. 找候选段，再核对完整意思；共享一个人物名不够。
4. 核对 Directions 的复用规则；不默认一段只能选一次，不按题号顺序匹配。
5. 犹豫时写两个候选段的具体差异，避免来回盲扫。

## 选词填空

列候选词的全部可能词性，再看空位结构。冠词后可能先有形容词；to 可能是介词或不定式标记。再检查数、时态、搭配、语义和篇章逻辑。

自编：The new policy has ____ access to public services.
在 improved / improvement / improving 中选 **improved**，因为 has + 过去分词构成现在完成时。

通读检查每项使用规则。总比例 5%，可在阅读内部后做；不能因此跨越收卷环节拖延。

## 考研精读复盘

训练时追踪论证链：话题 → 旧观点 → 作者修正 → 证据 → 结论。比较论点/例证、作者/他人、事实/建议。

错题卡：题干任务；证据范围；误选项；词汇/结构/范围/逻辑/时间错因；下次增加的一个动作。
