# 阅读理解完整攻略

## 四六级仔细阅读（传统阅读）详细流程

### 完整做题演示步骤

**Step 1：读题干（30秒）**
快速扫5道题的题干（不看选项），划出关键词（人名/地名/数字/特殊表达）。判断每道题是主旨题还是细节题。

**Step 2：读文章骨架（1.5分钟）**
- 精读第一段（把握话题和背景）
- 扫读每段首句（串起文章逻辑线）
- 精读最后一段（作者结论/态度）
→ 此时你应该能说出"这篇文章大概在讲什么"

**Step 3：逐题定位作答（6分钟）**
利用顺序原则——第1题答案在文章前半部分，第5题在文章后半部分。根据题干关键词回原文找对应段落，答案就在定位点上下2-3句内。

### 五种题型分类与对策

#### 1. 主旨题
- 问法："What is the main idea?" / "What is the passage mainly about?" / "The best title..."
- 解法：你已经通过读首段+各段首句+尾段掌握了中心，选最接近的
- 注意：正确选项通常是概括性的，不会太具体

#### 2. 细节题（占80%！）
- 问法：问具体信息、数据、观点
- 解法：题干关键词 → 回原文定位 → 原文信息同义改写就是答案
- 注意：答案几乎不会原词照搬，一定是**同义替换**

#### 3. 推断题
- 问法："It can be inferred that..." / "The author implies..."
- 解法：答案不会跑太远，就在定位段上下文
- 注意：推断≠脑补，必须有原文依据

#### 4. 态度题
- 问法："The author's attitude is..." 
- 解法：看尾段和文中评价性词汇（positive/negative/neutral/critical）
- 常见陷阱：indifferent（漠不关心）在学术文章中几乎不选

#### 5. 词义题
- 问法："The word/phrase '...' most probably means..."
- 解法：回原文看上下文语境推测，不要用你以前记的意思

### 选项排除四大陷阱（+ 2026.6 真题校准）

同学们记住啊，错误选项就那几种套路：

1. **过于绝对**：出现 all/every/never/always/only/must 这种绝对词的选项，通常是错的
2. **偷换概念 / 偷换对象**：用原文的词，但换了主语或宾语、范围（例：原文“许多人未晋升”≠ 选项“年轻人很少晋升”）
3. **以偏概全**：文章说了个例子，选项把它当成了全文结论
4. **无中生有**：选项说的内容原文压根没提，是出题人自己编的

**2026.6 官方解析里还高频出现的两类：**

5. **手段当目的**：原文写“用传感器检测疲劳”，干扰项写成“目标就是检测疲劳”——真正目标可能是“安全完成人车过渡”
6. **答非所问**：问“政策制定者在做什么”，干扰项给“税率下降的结果”——过程 ≠ 结果

**正确答案统一长相：** 对原文的 **同义转述**（paraphrase），不是原词搬运。

> 做阅读就像破案——证据（原文）在哪里，答案就在哪里。没有证据的选项，不管多像，都是嫌疑人，不是凶手。

### 讲题标准四步（解题教练模式必用）

1. 圈题干关键词  
2. 回原文定位（顺序原则）  
3. 写出「题干词 ↔ 原文词」映射  
4. 用上表点名杀掉三个干扰项  

完整第1套答案与题材见 `cet6-2026-06.md`。

### 四六级长篇阅读做题流程

1. 先读10个句子的题干，划出每个句子的2-3个关键词
2. 带着关键词扫读各段落
3. 关键词在哪个段落出现（原词或同义替换），那个段落就是答案
4. 一个段落可能对应多道题，也可能不对应任何题

### 考研阅读特别注意

- 考研阅读比四六级难得多，需要真正读懂每句话
- 精读三步法：读懂句子 → 理解段意 → 把握全文逻辑
- 考研阅读的干扰选项更隐蔽，需要更仔细对比原文
- 建议用真题精读训练，每篇文章都要搞透
