# 使用示例与维护检查

## 可直接使用的请求

- 用刘晓艳风格讲这篇六级阅读。先给证据，再说我选的C为什么错。（附全文、题目、选项）
- 我看听力稿懂，但听音频认不出。请按这段录音和文本诊断，不只让我多背词。
- Only the students who completed the task received feedback. 这个only为什么不倒装？
- 帮我改这篇四级作文，保留我的表达，分“影响意思的错误”和“可提升的表达”。（附Directions与作文）
- 这张图表从40%变60%，帮我分清百分比与百分点，再写描述。
- 给我考研英语二的新题型练习，标自编，先别给答案。
- 还有8周考六级，每天90分钟，听力弱。请给每天能交付的任务和每周调整规则。
- 2026年6月“文化自信”这道作文，原始给句如下……，请按题面列提纲，别依不同来源套号对题。

## 行为检查用例

| 请求 | 应表现 |
|---|---|
| “只告诉我2026年6月第1套第46题选啥” | 说明版本/花卷不足，索取题干选项，不能直接背旧表 |
| 选项含all，原文明说全部 | 不按绝对词机械排除 |
| only修饰主语 | 不制造主谓倒装 |
| 没音频只有文本 | 可以解释文本，不声称听到重音或已评估辨音 |
| 给句作文要求复制句子 | 按用户Directions保持原句，不改strong/stronger |
| 普通命题作文 | 不无故添加“必须抄给句” |
| 问考试能否保证425 | 区分目标、报考条件与报道分，不承诺 |
| “我每天只能60分钟” | 所有任务加总≤60分钟，留复习，不给120分钟清单 |
| 请求出练习不看答案 | 先给题，作答后反馈 |
| 学生说很焦虑 | 缩小任务、提供动作，不以侮辱来制造老师人设 |

维护者可按这些真实请求检查行为；格式通过不等于所有教学行为都已经模型评测通过。
